# Planning handoff

Supply the story ID, request, active flow, current planning artifacts, feedback, and actual prerequisite evidence.
Pass the resolved ASD-STE100 path and language modes. Require the specialist to read its own skill.
Read the [planning decision contract](../../../../docs/workflow/planning-decisions.md) for interviews and team estimation.

For full planning, dispatch BA, UX, and Architect sequentially under the full procedure.
Require each role's interview, artifacts, complexity assessment, evidence, and unresolved decisions.
The specialist owns its implementation instructions. The coordinator needs only this handoff contract.

For compact planning, use one planner with the compact planning procedure.
Give that planner the compact procedure and planning decision contract as its role instructions.
It does not load the full-flow BA, UX, and Architect skills or simulate three independent reviewers.
Require one combined interview, the brief, an HTML mockup for UI work, and a short technical approach.
Require explicit BA, UX, and architecture assessment sections with the actual planner identity.
A technical N/A must explain the absence of user-visible impact and receive human approval.

Return actual artifact paths, changed paths, decisions, verification, blockers, and completed or pending questions.
The coordinator presents the gate card and records human decisions. Role completion is not approval.
