# Verification handoff

Dispatch `f-verificator` with current approved planning artifacts, team decision, baseline identity, and an execution request.
Pass the language instructions and require the specialist to read its own skill.
Require independent test impact, staged manifest, exact QA changes, baseline GREEN, and expected acceptance RED.
Return exact case IDs, actual commands, evidence, readiness, and blockers. Preserve source and earlier evidence.

In compact execution, return the completed QA package to the coordinator before candidate preparation.
Record the QA manifest's fingerprint as the provisional packaging input. This is not human Gate 4 approval.
The compact dispatch package must present this manifest and the exact packaged candidate/control together.
