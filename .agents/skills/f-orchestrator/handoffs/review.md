# Review handoff

Dispatch separate implementation and UX reviewers against the same fixed candidate and inspected passing run.
Supply current planning, team decision, QA approval, control, case results, and candidate/base identities.
Pass language instructions and require each specialist to read its own review procedure.
Require independent assessments, criterion evidence, findings, disagreements, blockers, and recommendations.
Serialize shared report writes. Candidate or control changes require current evaluation and renewed affected approvals.

In compact execution, completed reviews feed the release package.
A recommendation does not become Gate 6 approval. A complete joint report without blockers permits only bounded session preparation.
