# Operator handoff

Dispatch `f-operator` with the requested action and actual baseline, planning, QA, control, and approval identities.
Pass the language instructions and require the specialist to read its own skill and applicable operational references.
Require isolated candidate/control/store paths, exact QA comparison, native setup checks, and verified sealed control.
Return dispatch evidence, actual model/configuration, budgets, candidate diff, and blockers before worker execution.
After execution, require native inspection, exact case outcomes, QA comparison, and fresh diagnostics for failure.

## Compact preparation only

This exception requires a recorded compact execution decision, current approved planning, and an explicit execution request.
The coordinator checks the completed independent QA package and pins its provisional manifest before dispatching preparation.
The Operator may provision and package this exact QA content before human Gate 4 approval.
This work stays in the isolated candidate and new control. It cannot launch a worker or change primary application source.
Supply the full provisional QA comparison for the combined dispatch review.
Assertions or manifests that change during packaging return to QA before presentation.

Human approval of the complete dispatch package must cover both Gate 4 and Gate 5 snapshots.
`--action run` always requires current explicit Gate 5 approval, exact control identity, model, and budget.
A mode flag, preparation request, or provisional manifest never grants launch authority.
