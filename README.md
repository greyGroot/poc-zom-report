# Empire English CRM (EE-CRM)

Enterprise customer relationship management and attendance reconciliation platform for Empire English.

## Overview

EE-CRM integrates with Schoolmate CRM and Zoom to provide verified attendance monitoring, teacher schedule tracking, and automated lesson reconciliation.
