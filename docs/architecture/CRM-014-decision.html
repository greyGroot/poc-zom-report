Use query-free breadcrumbs for parent navigation.

Pages supply ordered items to one shared component. Parent pages use their existing defaults. Remove only the duplicate normal day return link.

Decision and ownership

Breadcrumbs({ items }) renders labels in the supplied order at different hierarchy depths. Ancestors are links. Only the final item is current.

The schedule and day clients supply existing records and locale paths. The day client keeps any needed date formatter local.

Translations and scoped CSS provide breadcrumb-only copy, a shared baseline when the trail fits, full teacher-name wrapping, and accessible targets.

Ancestor paths copy no query parameters. There is no retention URL builder, global route resolver, or hierarchy registry.

R01 removes only the normal day day-details-back-link. Preserve error recovery, previous/next, schedule directory return, filters, authentication, lessons, and evidence.

Matching before and after views

Focused C4 views keep component positions stable. The page changes identify the exact removal. One shared renderer supports page-owned hierarchy depths.

One parent-navigation flow

  1. The administrator opens a day URL with or without parameters or browser history.
  2. The existing server page supplies route inputs and teacher-day data.
  3. The day client supplies ordered items with a query-free locale teacher path.
  4. The administrator activates the teacher ancestor. Next Link opens the schedule without query parameters.
  5. The schedule applies its existing current-week and status defaults. Error-recovery links keep their existing behavior.

Why this approach

A global layout resolver offers one insertion point but lacks teacher identity. Additional fetching or state propagation increases cost and stale-name risk.

Page-owned items use current data and support future depths. One shared renderer keeps semantics consistent without new routes, packages, APIs, or schema changes.

All 19 criteria remain mapped: 13 Add, five Preserve, and one narrowly scoped Retire. AC12 separately checks the retired normal link's absence.
